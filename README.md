# Casas Sevilla

Casas y pisos en venta en Sevilla capital y pueblos a 20 minutos o menos, de 50.000 a 170.000 €. Primero salen las listas para entrar a vivir, y se esconden las que necesitan obra. Incluye casas de banco (REO). Datos de Fotocasa, Idealista, pisos.com, Milanuncios, Tecnocasa, Servihabitat y Aliseda, sin anuncios repetidos.
